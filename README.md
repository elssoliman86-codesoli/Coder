# OneByte Coder

**الهدف:** بيئة تطوير محلية بمساعدة الذكاء الاصطناعي، بواجهة عربية أولًا، مع دعم الويب وAndroid عبر Capacitor.

> **حالة التطوير:** المشروع قيد التطوير. النسخة الحالية توفر إدارة مشاريع محلية، محرر أكواد، إعداد مزودي AI، وتوليدًا أوليًا لملفات المشروع. لا تزال المعاينة والتنفيذ الطرفي والوكلاء المتعددون والنشر على GitHub والاختبارات الفعلية على جهاز Android ضمن الأعمال المتبقية. راجع [حالة التنفيذ ومعايير القبول](docs/IMPLEMENTATION-STATUS.md).

## الموجود حاليًا

- إنشاء مساحات عمل محلية وعرض المشاريع وحذفها.
- إنشاء ملفات داخل المشروع وإعادة تسميتها وحذفها.
- محرر CodeMirror مع حفظ يدوي وتلقائي واختصار `Ctrl/Cmd + S`.
- إعداد مزودي OpenAI-compatible وNVIDIA NIM وOllama وcustom endpoints.
- اكتشاف الموديلات وإضافتها يدويًا واختبار اتصال فعلي بطلب محادثة.
- توليد أولي لملفات المشروع من خلال طلب AI واحد يعيد JSON.
- تخزين بيانات التطبيق في IndexedDB، مع تخزين مفاتيح المزودين منفصلة عن Zustand.

**مهم:** مفاتيح API في IndexedDB ليست مشفرة في هذه النسخة، ولا يوجد تكامل Android Keystore بعد. لا تستخدم جهازًا مشتركًا لحفظ مفاتيح حساسة.

## التقنية

- React 18 + TypeScript + Vite
- Tailwind CSS
- Capacitor Android
- CodeMirror 6
- Zustand + IndexedDB

## متطلبات التطوير

- Node.js 20+
- npm
- Java 17+ وAndroid SDK لبناء APK

## التشغيل المحلي

```bash
npm install
npm run dev
```

## الفحص والبناء

```bash
npm run typecheck
npm run test:run
npm run build
```

يجب الرجوع إلى GitHub Actions لمعرفة نتيجة الفحص على أحدث Commit. نجاح Web Build لا يثبت عمل API بمفتاح حقيقي ولا يثبت تشغيل APK على هاتف فعلي.

## Android

يوجد workflow لبناء Debug APK ورفعه كـArtifact عند نجاح تثبيت Android SDK وGradle وبناء التطبيق. لم يُعلن عن Release موقّع أو اختبار ميداني على جهاز Android إلا بعد التحقق الفعلي منهما.

## خارطة الطريق

المعاينة الآمنة، الطرفية المعزولة، التخطيط متعدد المراحل، البث وإلغاء طلبات AI، إدارة المهارات، GitHub publishing، وسجل التغييرات هي مراحل تطوير مستقبلية وليست وظائف مكتملة حاليًا.
