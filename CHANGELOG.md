## [0.1.0] - 2024-01-XX

### Added
- Foundation: Repository setup, design tokens, RTL shell, home screen with project cards
- VFS (Virtual File System) with IndexedDB/Dexie storage
- Project creation and import (including ZIP)
- Settings: Provider cards, Model table with status dots, GitHub token card, Skills manager
- Planner + Coder agents with live streaming editor
- Preview modes: Website (iframe), Mobile Runtime (phone frame), CLI (xterm.js + Pyodide)
- Visual Review Loop: Observer, Visual Critic, Fixer, stop conditions
- Edit Queue: persistent, reorderable, undoable
- Publish pipeline: Expert review, Quality Gate (10/10), Release Engineer, GitHub Actions workflows
- Accessibility audit (WCAG 2.2 AA), performance review
- Signed APK in GitHub Release, GitHub Pages deployment
